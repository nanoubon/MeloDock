MeloDock

เปลี่ยน Notch บน MacBook ให้เป็นแผงควบคุมเพลงที่เร็วและลื่นที่สุด
ดูเพลงที่กำลังเล่น, คุมการเล่น, ปรับเสียง, และสลับอุปกรณ์เสียงได้ทันที โดยไม่ต้องสลับหน้าต่างให้เสียสมาธิ

สิ่งที่ MeloDock ทำได้

• แสดง Now Playing: ปกเพลง, ชื่อเพลง, ศิลปิน, และ progress
• ควบคุมเพลงแบบเร็ว: Play / Pause / Next / Previous
• รองรับทั้ง Apple Music และ Spotify
• ปรับเสียงและสลับ output ได้ทันที (เช่น AirPods / ลำโพง)
• เรียกใช้งานด้วย Hotkey และตั้งให้เปิดพร้อมเครื่องได้
• ดีไซน์เบา ลื่น และโฟกัสการใช้งานจริงทุกวัน

ฟังเพลงต่อเนื่องได้แบบไม่สะดุด — นี่แหละประสบการณ์ใหม่ของการคุมเพลงบน Mac.
